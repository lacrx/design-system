# Overview

A stripped-down monochrome design. Black on white, no brand color. Lets content speak.

# Colors

Grayscale only. Near-black text on white background. Three gray levels for hierarchy.

# Typography

System fonts. No custom typefaces. Let the browser defaults handle it.

# Spacing

Moderate. 16px base rhythm. 24-32px between sections. 8-16px inside components.

# Components

Buttons: black fill, white text, no radius. Links: black, underline on hover. Cards: light border, no shadow.

# Do's and Don'ts

- DO: Keep it minimal. Every element earns its place.
- DON'T: Add color or decoration. The constraint is the point.
